# Coloring Masterpiece — SVG Vehicle Stencils

This version uses pre-made SVG coloring-book stencils for the Vehicles category.

## Run with VS Code Live Server

Keep this structure intact:

- index.html
- app.js
- assets/stencils/vehicles/*.svg

Open the project folder in VS Code and use **Open with Live Server** on `index.html`.

The SVGs are intentionally transparent outside the illustration and use closed white-filled regions with dark outlines so they work with the existing canvas flood-fill system.
